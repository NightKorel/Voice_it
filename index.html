無限煉製

把清單裡的東西拖到這裡（手機點一下就會放上來），
再把兩個東西疊在一起，看看會煉出什麼。

設定

這個遊戲用 Google 的 Gemini 免費方案來想「合出來是什麼」。你需要一把自己的鑰匙（API key），免費、不用綁信用卡。

  1. 打開 Google AI Studio 的鑰匙頁面，用 Google 帳號登入。
  2. 按「Create API key」（建立 API 金鑰），建好後按複製。
  3. 貼到下面的格子，按「儲存」。

鑰匙只存在這台裝置的這個瀏覽器裡，不會上傳到任何地方（只會拿去問 Gemini）。換手機或換瀏覽器要重新貼一次。

預設 gemini-2.5-flash-lite：免費版每天約 1000 次、每分鐘 15 次。合過的組合會記住，重複合不會花次數。

存檔

你的發現存在這個瀏覽器裡。想換裝置或怕不見，可以匯出成檔案備份，之後再匯入。
